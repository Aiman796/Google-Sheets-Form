HTML FORM WITH GOOGLE SHEETS INTEGRATION

Project Description:
A responsive HTML form that collects user information
and stores the submitted data automatically in Google Sheets.

Technologies Used:
- HTML
- CSS
- JavaScript
- Google Apps Script
- Google Sheets

Form Fields:
- Full Name
- Email Address
- Phone Number
- Gender
- Date of Birth
- City
- Message / Comments

Features:
- HTML validation
- Responsive design
- Google Sheets integration
- Success message
- Mobile-friendly interface

Project Flow:

User
↓
HTML Form
↓
JavaScript
↓
Google Apps Script
↓
Google Sheet
